Welcome to the bento documentation!

bento is a fork of [niri](https://github.com/niri-wm/niri) where tiling is done by a [layout engine](./Configuration:-Tiling-Layouts.md).
Feel free to look through usage and [Getting started](./Getting-Started.md).
If you're looking for ways to configure bento, check out the [introduction to configuration](./Configuration:-Introduction.md).

bento is not accepting contributions until 2027.
For questions, use [GitHub](https://github.com/faetalize/bento) or the [Discord server](https://discord.gg/EZFTEvWWxC) (@faetalize).

---

The documentation lives in the `docs/wiki/` folder of the repository, see [Documenting bento](./Development:-Documenting-bento.md).
